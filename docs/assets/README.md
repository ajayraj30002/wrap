# WRAP Documentation Assets & Media Vault

Place your visual assets (screenshots, screen recordings, GIFs) in this directory according to the table below. The root `README.md` is pre-configured to link directly to these paths.

| Filename | Purpose | Recommended Format | Suggested Dimensions |
| :--- | :--- | :--- | :--- |
| `dashboard-overview.png` | Main Hero: Enterprise Control Room Overview dashboard | High-res PNG | 1920 × 1080 (16:9) |
| `dag-pipeline.gif` | Live DAG execution pipeline showing real-time workstream routing & striping | Animated GIF / WebP | 1280 × 720 or 1600 × 900 |
| `analytics-dashboard.png` | Deep telemetry, cost burn-down, latency P95/P99 charts | High-res PNG | 1920 × 1080 (16:9) |
| `operator-login.png` | Operator Security Enclave / Login interface with crest | High-res PNG | 1920 × 1080 (16:9) |
| `model-tiers-budgets.png` | Virtual model tiers, budget limits & policy management | High-res PNG | 1920 × 1080 (16:9) |
| `worker-topology.png` | Live worker grid, health monitors & provider credentials | High-res PNG | 1920 × 1080 (16:9) |

> **Note:** WRAP's header brand crest automatically loads directly from `frontend/public/wrap-app-icon.png`.
